# 📋 Agenda

A command-line task management application built with Python.

Agenda helps you organize your daily tasks with completion, priorities, due dates, notes, and persistent storage using JSON.

---

 ✨ Features

- ➕ Add new tasks
- 👀 View all tasks
- ✅ Mark tasks as completed
- ✏️ Edit existing tasks
- 🗑 Delete tasks
- 🔍 Search tasks by keyword
- 📅 Add optional due dates
- 📝 Add optional notes
- ⚡ Set task priorities (Low, Medium, High)
- 📂 Automatically save tasks using JSON
- 📋 Sort tasks by:
  - Priority
  - Completion status
  - Name
  - Default combined sorting

---

## 🛠 Technologies Used

- Python
- JSON
- Datetime module

---

## 🚀 How to Run

1. Clone this repository

```bash
git clone https://github.com/kumariananya1097-ai/Agenda.git
```

2. Navigate to the project folder

```bash
cd Agenda
```

3. Run the program

```bash
python agenda.py
```
